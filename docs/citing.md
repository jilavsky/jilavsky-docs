# How to cite

If these tools contribute to a publication, please cite:

- **Irena**: J. Ilavsky and P. R. Jemian, "Irena: tool suite for modeling and analysis of
  small-angle scattering", *J. Appl. Cryst.* **42**, 347–353 (2009).
  [doi:10.1107/S0021889809002222](https://doi.org/10.1107/S0021889809002222)
- **Nika**: J. Ilavsky, "Nika: software for two-dimensional data reduction",
  *J. Appl. Cryst.* **45**, 324–328 (2012).
  [doi:10.1107/S0021889812004037](https://doi.org/10.1107/S0021889812004037)

pyIrena implements the Irena methods, so cite the Irena paper for pyIrena results.
