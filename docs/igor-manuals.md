# Igor Pro manuals: Irena, Nika, Indra

The manuals for the Igor Pro packages are a separate site with their own release versions:

**<https://saxs-igorcodedocs.readthedocs.io/en/stable/>**

- [Irena](https://saxs-igorcodedocs.readthedocs.io/en/stable/Irena/index.html): analysis
- [Nika](https://saxs-igorcodedocs.readthedocs.io/en/stable/Nika/index.html): 2D data reduction
- [Indra](https://saxs-igorcodedocs.readthedocs.io/en/stable/Indra/index.html): USAXS data reduction

That site keeps its old address on purpose: the Help buttons in released Igor code open pages on
it directly, so its addresses never change.

If you are moving from Irena to pyIrena, see {doc}`irena-pyirena-map`.
